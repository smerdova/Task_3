## Задание 3: веб-приложение

### Автотесты для проверки программы, которая помогает заказать бургер в Stellar Burgers

### Реализованные сценарии

Созданы автотесты для веб-приложения [Stellar Burgers](https://stellarburgers.education-services.ru), покрывающие сценарии: Восстановление пароля, Личный кабинет, Проверка основного функционала, Раздел «Лента заказов».
Протестирована функциональность в двух браузерах: Google Chrome и Mozilla Firefox.

### Структура проекта

- `page` - пакет, содержащий страницы c отдельными классами с Page Object.
- `tests` - пакет, содержащий тесты, разделенные по классам.
- `locators` - пакет, в котором хранятся все локаторы отдельно по страницам.

### Запуск автотестов

> `$ pytest`

**Установка зависимостей**

> `$ pip3 install -r requirements.txt`
